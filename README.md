# Alazar Walle | Portfolio

A personal portfolio website built with HTML to showcase my background as a Software Engineering student at Addis Ababa Science and Technology University (AASTU), my skills, projects, and university coursework.

## Features
- **Home (`index.html`)**: Personal bio, skills roadmap, tools list, and a detailed education history table including courses, credit hours, and grades.
- **Projects (`projects.html`)**: Detailed breakdown of projects with step-by-step build guides and tech stacks.
